# 営業会議レポートメーカー

営業担当者の目標・実績・訪問数を集計し、達成率、会議用報告文、CSV、印刷用レポートを生成する無料試作版です。

## 使い方
`index.html` をブラウザで開き、サンプルボタンで動作確認してください。入力はブラウザのlocalStorageに保存され、外部サーバーへ送信されません。顧客名など機密情報は入力しないでください。

## 公開方法
Cloudflare PagesでGitHubリポジトリを接続し、静的サイトとしてデプロイします。ビルドコマンド不要、出力ディレクトリは `/` です。
